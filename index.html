Event Maze Runner 5 hari di map CTM

Client punya map Maze Runner dan mau bikin event 5 hari: tiap hari ada misi baru, ada malam di mana pintu maze nggak nutup, dan pemain yang sering mati makin lemah. Saya pasang servernya dari nol, lalu bikin dua plugin buat jalanin aturan event-nya.

MazeEvent

  • Misi harian lewat /quest, kebuka sesuai hari event. Hari ganti jam 06.00 WIB, bukan tengah malam, biar sesi RP yang lewat jam 12 tetap dihitung hari yang sama.
  • Malam Glade: Griever muncul bergelombang di sekitar Glade (3 per gelombang, maksimal 12), bossbar hitung mundur, dan daftar yang selamat diumumkan pas pagi.
  • Waktu malam diatur supaya trigger ruang kontrol bawaan map (tick 13250, 16000, 20000) tetap kepanggil, jadi mekanik map nggak rusak.
  • World tambang terpisah lewat /tambang: lubang 41 x 30 blok, isi ore diatur di config, diisi ulang tiap 30 menit.

DeathHeartLoss

  • Tiap mati, darah maksimal turun 1 hati. Hati habis berarti pemain jadi spectator.
  • Item Hati Kehidupan buat nambah hati lagi, maksimal 20 hati. Jadi hadiah buat yang selamat di malam Glade.
  • Title, actionbar, dan suara dicek tampil sama di Java dan Bedrock.

Server SMP crossplay: ikon rank, pack Bedrock, dan sistem denda mati

  • Ikon rank di-recolor dari gambar referensi client, dikasih padding simetris biar nggak nempel ke nama, lalu dipasang lewat ItemsAdder dan prefix TAB (%img_dev-icon%).
  • Pemain Bedrock nggak lihat ikon karena dua hal: manifest.json pack lama ada di dalam subfolder, dan glyph-nya di page E2 padahal ItemsAdder pakai E0. Pack dibangun ulang (v1.2) dengan mapping U+E01B sampai U+E037 dan dipaksa download lewat Geyser.
  • Senjata custom dari ItemsAdder dibikinin versi Bedrock (attachable + geo model). Modelnya karya Cviko, kreditnya tetap ditulis di lore item.
  • Denda mati malam (Skript + SkBee): item ditahan, lalu muncul menu tebusan 30%, 50%, atau 100%. Denda naik 5.000 koin per kematian sampai 500.000, lalu reset kalau dibayar. Bisa dibuka lagi lewat /tebus.
  • Ditambah susunan shop EconomyShopGUI Premium, HUD BetterHud, dan desain tablist.

Plugin shop GUI untuk Paper 26.2

Client minta shop yang tampilannya sama dengan shop DonutSMP, jalan di Paper 26.2 dan Folia. Saya tulis plugin baru dari nol dengan target Java 25.

  • /shop dengan 5 kategori, halaman per kategori, dan menu konfirmasi jumlah beli.
  • /sell buka GUI 45 slot, item terjual otomatis pas GUI ditutup. Isi shulker box ikut dihitung, item yang nggak laku dibalikin.
  • /worth, /sellhistory, /setworth, dan 10 daftar harga jual.
  • Dua mata uang: Vault untuk shop biasa, Shards untuk shard shop (spawner dan item khusus).
  • Slot inventory dicek dulu sebelum transaksi, biar item nggak hilang kalau inventory penuh.

Setup SMP yang ringan pakai Skript

Server kecil yang nggak butuh plugin berat. Fitur-fiturnya cukup ditulis di Skript, sisanya setting plugin yang udah ada.

  • Slowmode chatJeda 3 detik per pesan, ada sisa waktu tunggu yang ditampilin. Staff bisa bypass lewat permission.
  • Clearlag terjadwalItem di tanah dibersihin tiap 15 menit, dengan peringatan 60, 30, 10, dan 5 detik sebelumnya. Admin bisa jalanin manual lewat /clearlag.
  • Toggle night vision/nv nyala atau mati per pemain, dan pilihannya disimpan.
  • Setting pluginTAB dan PlaceholderAPI, kit PvP, harga EconomyShopGUI dan SellWorth. File diupload ke server lewat SFTP.

Cara saya ngerjain

Urutan ini bukan janji di atas kertas. Tiap langkah ada jejaknya di project yang udah selesai.

  1. 01

    Brief dan referensi

    Kamu kirim versi server, plugin yang udah ada, dan contoh gambar atau server yang jadi acuan.

    Di project ikon rank, gambar mentah dari client jadi patokan warna dan bentuk.

  2. 02

    Dikerjain di server lokal dulu

    Saya jalanin Paper dengan versi yang sama di komputer saya, jadi server kamu nggak ikut berantakan selama proses.

    Event Maze Runner diuji di Paper 1.21.8 lokal bareng map aslinya sebelum dipasang.

  3. 03

    Preview sebelum dipasang

    Buat kerjaan tampilan, kamu dapat gambar perbandingan dan beberapa varian buat dipilih.

    Ikon rank dikirim dalam varian 16x16 tanpa padding, kanvas 12 px, dan stroke tebal.

  4. 04

    Backup, lalu pasang

    File asli di server dibackup dulu, baru file baru diupload lewat SFTP dan di-reload.

    Tekstur asli server disimpan terpisah sebelum ikon rank diganti.

  5. 05

    Serah terima dengan dokumentasi

    Kamu dapat catatan lokasi file, daftar command admin, permission, dan cara reload.

    Sistem denda mati malam dikirim bareng panduan command /dp dan langkah ngetesnya.

Pertanyaan yang sering masuk

Server saya di hosting panel. Bisa dikerjain?

Bisa. Saya butuh akses SFTP atau sub-user di panel. Project sebelumnya juga dipasang lewat SFTP panel. Setelah selesai, aksesnya bisa kamu cabut.

Pemain Bedrock (HP, konsol) bisa ikut main?

Bisa, pakai Geyser dan Floodgate. Kalau server pakai resource pack custom seperti ikon rank atau senjata custom, pack versi Bedrock-nya perlu dibikin terpisah. Itu dibahas pas brief.

Versi Minecraft apa yang bisa?

Yang udah pernah saya kerjain: Paper 1.21.x dan Paper 26.2 dengan Java 25. Pemain yang masih pakai client versi lama bisa tetap masuk lewat ViaVersion, ViaBackwards, dan ViaRewind.

Untuk plugin custom, saya dapat apa aja?

File .jar siap pasang dan config.yml yang bisa kamu ubah sendiri. Source code project-nya (Maven atau Gradle) masuk tambahan Rp75.000.

Fitur yang saya mau nggak ada di daftar. Gimana?

Centang yang paling mendekati, lalu jelasin di kolom catatan. Kalau ternyata perlu plugin baru, saya kasih tahu harganya dulu sebelum mulai.
